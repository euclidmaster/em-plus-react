시스템 소개 및 로그인
EM+ 학습관리 시스템을 처음 사용하는 원장님을 위한 안내
EM+ 시스템이란?

EM+ 학습관리 시스템은 학원의 학생 학습 이력, 출결, 성과, 선생님-학생 소통을 한 곳에서 관리할 수 있는 통합 플랫폼입니다. 원장(admin), 선생님(teacher/assistant), 학생(student) 세 가지 역할로 운영되며, 각 역할에 맞는 화면과 권한이 부여됩니다.

👨‍💼
원장 (Admin)전체 학생·선생님 관리, 모든 데이터 열람, 계정 승인, 리포트 조회
👩‍🏫
선생님 (Teacher/Assistant)담당 학생 관리, 클리닉 세션 운영, 학습 기록 작성
🎒
학생 (Student)본인 학습 기록 확인, 과제·출결 조회, 선생님과 소통
🌐
접속 방법PC, 태블릿, 스마트폰 — 별도 앱 설치 없이 브라우저로 바로 접속
시스템 접속 주소
🌐 접속 URL: https://em-plus-react.vercel.app
PC, 태블릿, 스마트폰 모두 사용 가능합니다. Chrome, Edge, Safari 등 최신 브라우저를 권장합니다.
로그인 방법
  • 1브라우저 주소창에 접속 URL을 입력하거나, 저장된 북마크를 클릭합니다.
  • 2로그인 화면에서 이메일 주소와 비밀번호를 입력합니다.
  • 3로그인 버튼을 클릭하면 본인 역할(원장)에 맞는 대시보드 화면으로 이동합니다.
  • 4로그인 후 좌측 상단 로고 옆에 원장 이름이 표시됩니다. 잘못된 계정이면 로그아웃 후 다시 로그인합니다.
⚠ 주의: 원장 계정은 role이 admin으로 설정되어야 모든 메뉴에 접근 가능합니다. 문제가 있다면 시스템 관리자에게 문의하세요.
💡 팁: 비밀번호를 잊은 경우 로그인 화면 하단 "비밀번호 찾기"를 이용하거나 가입 이메일의 리셋 메일을 확인하세요.

대시보드 구성 요소

홈 화면은 원장님이 학원의 현재 상태를 한눈에 파악할 수 있도록 설계되었습니다.

구성 요소내용위치
오늘의 출석 현황전체 출석 / 결석 / 지각 인원 수 카드상단 요약 카드
최근 등록 학생최근 가입 또는 승인된 학생 목록중단 리스트
이번 달 클리닉이번 달 클리닉 세션 수 / 항목 수상단 요약 카드
미확인 메시지학생·선생님이 보낸 읽지 않은 메시지 수상단 아이콘 배지
좌측 사이드바 메뉴 구조
  • 🏠홈 — 대시보드 메인 페이지
  • 👥학생 관리 — 학생 명단 조회 및 개인 정보 수정
  • 📊학습현황 — 주간플랜, 일일기록, 숙제, 수행평가, 클리닉 관리, 클리닉 리포트
  • 📋운영 관리 — 게시판, 출석 관리
  • 👨‍🏫선생님 관리 — 선생님 계정 승인 및 목록
  • 💬소통 — 학생·선생님과의 메시지
💡 팁: 화면 상단 헤더에는 현재 위치(Breadcrumb)가 표시되어, 지금 어느 메뉴에 있는지 항상 확인할 수 있습니다.
알림 확인
  • 1상단 헤더 우측의 종 아이콘(🔔)을 클릭하면 최신 알림이 표시됩니다.
  • 2읽지 않은 알림은 빨간색 배지로 개수가 표시됩니다.
  • 3알림 항목 클릭 시 해당 페이지로 바로 이동합니다.

학생 관리
학생 명단 조회, 개인정보 수정, 성적 확인
학생 목록 조회
  • 1좌측 메뉴 학생 관리를 클릭합니다.
  • 2전체 학생 목록이 테이블 형태로 표시됩니다. 이름, 학년, 담당 선생님, 가입일이 표시됩니다.
  • 3상단 검색창에 학생 이름 또는 학년을 입력하면 실시간으로 필터링됩니다.
  • 4학생 이름 클릭 시 해당 학생의 상세 프로필 페이지로 이동합니다.
학생 상세 프로필

학생 이름을 클릭하면 해당 학생의 모든 정보를 한 페이지에서 확인할 수 있습니다.

탭내용
기본 정보이름, 학년, 연락처, 담당 선생님, 수강 과목
학습 기록주간 플랜, 일일 학습 기록 조회
성적과목별 점수 입력 및 차트 시각화
출결월별 출석·결석·지각 기록
클리닉해당 학생의 클리닉 이력
학생 정보 수정
  • 1학생 상세 페이지에서 정보 수정 버튼을 클릭합니다.
  • 2이름, 학년, 담당 선생님 등 수정할 항목을 변경합니다.
  • 3저장 버튼을 클릭하면 변경 내용이 즉시 반영됩니다.
⚠ 주의: 학생의 이메일 주소는 로그인 계정과 연동되어 있어 원장도 직접 수정할 수 없습니다. 변경이 필요하면 새 계정 생성 후 기존 계정 비활성화를 권장합니다.
성적 조회 및 차트
  • 1학생 상세 프로필 → 성적 탭으로 이동합니다.
  • 2과목별 시험 점수가 테이블과 꺾은선 차트로 표시됩니다.
  • 3상단 성적 입력 버튼을 통해 새 시험 점수를 추가할 수 있습니다.
  • 4차트 우측 상단에서 기간 필터(전체/최근 6개월/최근 1년)를 변경할 수 있습니다.
💡 팁: 성적 차트는 선생님과 학생도 확인할 수 있습니다. 다만 입력/수정은 선생님과 원장만 가능합니다.

학습 관리
주간플랜, 일일기록, 숙제, 수행평가 관리
주간 학습 플랜
  • 1좌측 메뉴 학습현황 → 주간플랜을 선택합니다.
  • 2상단에서 학생 이름을 선택하고, 조회할 날짜(주)를 설정합니다.
  • 3해당 주의 요일별 학습 계획이 카드 형식으로 나타납니다.
  • 4원장은 모든 학생의 플랜을 열람할 수 있으며, 수정이 필요한 경우 담당 선생님에게 전달합니다.
일일 학습 기록
  • 1좌측 메뉴 학습현황 → 일일기록을 선택합니다.
  • 2학생 선택 → 날짜 선택 후 해당 날의 학습 메모, 과제 완료 여부를 확인합니다.
  • 3선생님이 작성한 메모와 학생의 자기평가를 모두 볼 수 있습니다.
숙제 관리
  • 1학습현황 → 숙제 메뉴로 이동합니다.
  • 2날짜와 학생을 선택하면 과목별 숙제 목록과 완료 여부가 표시됩니다.
  • 3원장은 전체 학생의 숙제 이행률을 한눈에 파악할 수 있습니다.
📌 참고: 숙제 미완료율이 높은 학생을 발견하면 담당 선생님에게 면담을 요청할 수 있습니다.
수행평가 관리
  • 1학습현황 → 수행평가로 이동합니다.
  • 2학생별, 과목별 수행평가 점수가 테이블로 표시됩니다.
  • 3선생님이 입력한 점수와 피드백을 조회할 수 있습니다.
  • 4원장은 수행 점수를 직접 입력하거나 기존 점수를 수정할 수 있습니다.

클리닉 관리
학생별 심층 학습 지원 세션 관리
클리닉이란?

클리닉은 특정 학생이 어려워하는 부분을 집중 지도하기 위한 1:1 또는 소그룹 세션입니다. 선생님이 클리닉 세션을 생성하고, 각 세션 안에 구체적인 학습 항목(문제 유형, 개념 등)을 기록합니다. 원장은 모든 학생의 클리닉 기록을 조회하고 현황을 파악할 수 있습니다.

📌 구조: 클리닉 세션(날짜/제목/담당선생님) → 클리닉 항목(개별 학습 기록)
클리닉 세션 조회
  • 1좌측 메뉴 학습현황 → 클리닉 관리를 클릭합니다.
  • 2상단에서 조회할 학생과 날짜를 선택합니다.
  • 3해당 날짜에 등록된 클리닉 세션 카드들이 표시됩니다.
  • 4각 세션 카드를 클릭하면 세션 내 항목 목록이 펼쳐집니다.
클리닉 세션 생성
  • 1클리닉 관리 페이지에서 우측 상단 + 세션 추가 버튼을 클릭합니다.
  • 2세션 제목(예: "수학 이차방정식 클리닉"), 날짜를 입력합니다.
  • 3저장 버튼을 클릭하면 세션 카드가 생성됩니다.
  • 4세션 카드 내부의 + 항목 추가를 클릭하여 학습 항목을 입력합니다.
💡 팁: 세션 색상은 자동으로 배정됩니다. 서로 다른 색상으로 여러 세션을 구분하면 한눈에 파악하기 편합니다.
클리닉 항목 관리
동작방법
항목 추가세션 카드 내 "+ 항목 추가" 버튼 → 내용 입력 후 Enter 또는 저장
항목 수정항목 텍스트 클릭 → 인라인 편집 가능
항목 삭제항목 우측 휴지통 아이콘 클릭
세션 삭제세션 카드 상단 ⋯ 메뉴 → 세션 삭제 (하위 항목 전체 삭제)
🚨 주의: 세션 삭제 시 해당 세션의 모든 항목이 함께 삭제됩니다. 삭제 전 내용을 확인하세요.

클리닉 리포트 & AI 요약
월별 클리닉 분석 및 AI 학습 요약 리포트
클리닉 리포트란?

월 단위로 특정 학생의 클리닉 기록을 집계하여 과목별 세션 수, 항목 수, 주요 학습 내용을 시각적으로 보여주는 리포트입니다. 인쇄 또는 PDF 저장이 가능하며, AI 요약 기능으로 핵심 내용을 자동 정리합니다.

리포트 조회 방법
  • 1좌측 메뉴 학습현황 → 클리닉 리포트를 클릭합니다.
  • 2상단에서 학생을 선택하고 연도/월을 지정합니다.
  • 3해당 월의 클리닉 세션 수, 항목 수, 과목 분포 차트가 표시됩니다.
  • 4하단에는 세션별 상세 항목 목록이 펼쳐집니다.
AI 요약 기능
  • 1리포트 화면 우측 상단의 AI 요약 토글을 클릭합니다.
  • 2AI가 해당 월의 클리닉 항목을 분석하여 학습 패턴, 약점 분야, 진전 사항을 요약합니다.
  • 3요약 결과는 화면에 텍스트로 표시되며, 인쇄 시 함께 포함됩니다.
📌 AI 요약 활용법: 학부모 상담 자료로 활용하거나, 다음 달 학습 계획 수립에 참고합니다. AI가 생성한 내용을 그대로 사용하기보다 선생님이 검토 후 활용하세요.
⚠ 참고: AI 요약은 서버에 API 키가 설정된 경우에만 작동합니다. 설정이 안 된 경우 오류 메시지가 표시됩니다.
리포트 인쇄 / PDF 저장
  • 1리포트 화면 우측 인쇄 버튼을 클릭합니다.
  • 2브라우저 인쇄 창이 열립니다. 프린터는 PDF로 저장을 선택하면 PDF 파일로 내보낼 수 있습니다.
  • 3사이드바, 헤더 등 불필요한 UI는 자동으로 숨겨지고 리포트 내용만 인쇄됩니다.

운영 관리
게시판, 출결 관리
게시판 관리
  • 1좌측 메뉴 운영 관리 → 게시판을 클릭합니다.
  • 2공지사항, 학습 자료 등의 게시물 목록이 표시됩니다.
  • 3새 글 작성 버튼으로 공지사항을 등록할 수 있습니다.
  • 4게시물에 파일 첨부가 가능하며, 학생 및 선생님 모두 조회 가능합니다.
💡 팁: 중요 공지는 상단 고정 설정을 이용하면 목록 최상단에 항상 표시됩니다.
출결 관리
  • 1좌측 메뉴 운영 관리 → 출석 관리를 클릭합니다.
  • 2날짜를 선택하면 해당일 학생별 출결 현황(출석/결석/지각)이 표시됩니다.
  • 3출결 상태를 클릭하여 변경할 수 있습니다.
  • 4월별 출결 집계 테이블에서 개인별 출석률을 확인할 수 있습니다.
📌 참고: 출결 데이터는 학생의 수업료 환불, 경고 처리 등 학원 운영에 중요한 근거 자료가 됩니다. 정확하게 기록해 주세요.

선생님 관리 & 계정 승인
선생님 계정 승인, 역할 설정, 담당 학생 배정
신규 선생님 계정 승인
  • 1선생님이 시스템에 회원가입하면 승인 대기 상태가 됩니다.
  • 2좌측 메뉴 선생님 관리로 이동하면 대기 중인 계정 목록이 표시됩니다.
  • 3계정 옆 승인 버튼을 클릭하면 즉시 활성화됩니다.
  • 4역할(teacher / assistant)을 선택 후 승인합니다. 조교(assistant)는 일부 기능이 제한됩니다.
⚠ 주의: 승인 전까지 해당 선생님은 시스템에 로그인은 되지만 어떤 메뉴도 이용할 수 없습니다. 신속히 승인해 주세요.
선생님 역할 구분
역할권한특징
teacher클리닉 세션 생성·수정, AI 리포트, 학습 기록 작성담당 학생 전체 관리
assistant클리닉 항목 입력, 학습 기록 조회세션 생성은 담당 teacher와 공유
담당 학생 배정
  • 1선생님 관리 페이지에서 선생님 이름 클릭 → 상세 화면으로 이동합니다.
  • 2담당 학생 관리 탭에서 배정할 학생을 체크합니다.
  • 3저장 클릭 시 즉시 반영됩니다. 선생님은 배정된 학생만 볼 수 있습니다.
💡 팁: 한 학생을 여러 선생님에게 배정할 수 있습니다. 주요 담당 선생님과 조교를 함께 배정하면 효율적으로 운영할 수 있습니다.
선생님 계정 비활성화
  • 1선생님 관리 목록에서 비활성화할 선생님의 ⋯ 메뉴를 클릭합니다.
  • 2계정 비활성화를 선택합니다.
  • 3비활성화된 계정은 로그인이 불가능하며, 담당 학생도 자동으로 해제됩니다.
🚨 주의: 비활성화는 계정 삭제와 달리 데이터는 보존됩니다. 해당 선생님이 작성한 클리닉 기록, 학습 메모 등은 유지됩니다.
