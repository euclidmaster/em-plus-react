접속 주소
🌐 접속 URL: https://em-plus-react.vercel.app
스마트폰, 태블릿, PC 어디서든 브라우저로 접속할 수 있습니다. 앱 설치가 필요 없어요!
💡 팁: 스마트폰에서 사파리(iOS) 또는 크롬(Android)으로 접속한 뒤 "홈 화면에 추가"를 선택하면 앱처럼 바로가기를 만들 수 있어요.
회원가입 방법
  • 1접속 주소로 이동 → 로그인 화면 하단 "회원가입"을 클릭합니다.
  • 2이메일 주소, 비밀번호, 이름을 입력하고 가입 버튼을 클릭합니다.
  • 3가입 후 원장님 또는 선생님이 계정을 승인해야 시스템을 이용할 수 있습니다.
  • 4승인이 완료되면 로그인 후 모든 메뉴를 이용할 수 있습니다.
⚠ 주의: 가입 후 승인 전까지는 화면이 비어 있거나 "승인 대기 중" 메시지가 표시됩니다. 선생님께 승인을 요청하세요.
로그인 방법
  • 1접속 주소로 이동하면 로그인 화면이 나타납니다.
  • 2가입할 때 사용한 이메일과 비밀번호를 입력합니다.
  • 3로그인 버튼을 클릭하면 내 학습 대시보드로 이동합니다.
💡 비밀번호를 잊었다면: 로그인 화면 하단 "비밀번호 찾기"를 클릭하면 가입 이메일로 재설정 링크가 전송됩니다.

주간 학습 플랜 확인
선생님이 작성한 이번 주 학습 계획 보기
주간 플랜이란?

주간 플랜은 선생님이 나를 위해 만든 이번 주 학습 계획표입니다. 요일별로 어떤 과목을, 어떤 내용을, 얼마나 공부해야 하는지 안내해줍니다. 플랜을 보면서 오늘 해야 할 공부를 확인하고, 완료하면 체크해보세요!

📌 알아두세요: 플랜의 내용은 선생님만 작성할 수 있습니다. 내가 수정할 수 없지만, 완료 체크는 내가 직접 할 수 있어요.
주간 플랜 보는 방법
  • 1좌측 메뉴에서 주간 플랜을 클릭합니다.
  • 2이번 주 월요일~일요일의 학습 계획이 요일별 카드로 나타납니다.
  • 3오늘 날짜 카드는 강조 표시되어 쉽게 찾을 수 있습니다.
  • 4각 항목에는 과목, 학습 내용, 예상 시간이 표시됩니다.
완료 체크하기
  • 1공부를 마친 항목 왼쪽의 ○ 체크박스를 클릭합니다.
  • 2체크하면 항목이 완료 색상(회색/취소선)으로 바뀝니다.
  • 3상단의 완료율 바가 올라가는 것을 확인할 수 있습니다.
  • 4잘못 체크했으면 다시 클릭하면 해제됩니다.
💡 팁: 매일 플랜을 확인하고 완료 체크를 하면 선생님도 내 학습 진행 상황을 바로 알 수 있어요. 열심히 하는 모습을 보여주세요! 💪
지난 주 / 다음 주 보기
  • 1화면 상단 날짜 옆의 ← → 화살표를 클릭하면 다른 주를 볼 수 있습니다.
  • 2지난 주 플랜과 완료 기록도 그대로 남아 있습니다.
  • 3오늘 버튼을 클릭하면 이번 주로 돌아옵니다.
4
숙제 확인 및 체크
선생님이 등록한 숙제 목록 확인 및 완료 처리
숙제 목록 보기
  • 1좌측 메뉴에서 숙제를 클릭합니다.
  • 2오늘 날짜 기준의 숙제 목록이 나타납니다.
  • 3각 숙제에는 과목, 내용, 마감일이 표시됩니다.
  • 4날짜 화살표를 클릭해 다른 날의 숙제도 볼 수 있습니다.
📌 참고: 숙제는 선생님이 등록합니다. 숙제 내용이 없거나 궁금한 점이 있으면 선생님에게 메시지로 문의하세요.
숙제 완료 체크
  • 1숙제를 마친 후 해당 항목 왼쪽의 체크박스를 클릭합니다.
  • 2완료된 숙제는 목록 하단으로 이동하며 취소선이 그어집니다.
  • 3선생님도 내 완료 체크를 실시간으로 확인할 수 있습니다.
⚠ 주의: 숙제를 완료 체크한다고 해서 자동으로 제출되는 것은 아닙니다. 실제 숙제물은 수업 시간에 선생님에게 직접 제출해야 해요.
미완료 숙제 확인
  • 1숙제 목록 상단에 미완료 항목이 먼저 표시됩니다.
  • 2마감일이 지난 미완료 숙제는 빨간색으로 강조 표시됩니다.
  • 3홈 화면에서도 오늘 기준 미완료 숙제 수를 바로 확인할 수 있습니다.
💡 팁: 숙제를 마치면 바로 체크하는 습관을 만들어 보세요. 선생님이 내 노력을 더 잘 알 수 있습니다!

내 성적 조회
과목별 시험 점수 및 성적 변화 추이 확인
성적 화면 열기
  • 1좌측 메뉴에서 성적을 클릭합니다.
  • 2선생님이 입력한 내 시험 점수 목록이 나타납니다.
  • 3상단 탭에서 과목을 선택하면 해당 과목만 필터됩니다.
성적 차트 보기
  • 1성적 목록 상단의 차트 보기 버튼을 클릭합니다.
  • 2시간 순서대로 점수 변화를 보여주는 꺾은선 그래프가 나타납니다.
  • 3여러 과목을 함께 표시하거나 특정 과목만 선택해서 볼 수 있습니다.
  • 4차트 상단에서 기간 필터(전체 / 최근 6개월 / 최근 1년)를 변경할 수 있습니다.
💡 팁: 성적 차트를 통해 어떤 과목이 오르고 있는지, 어디가 약한지 스스로 파악할 수 있어요. 선생님과 상담 전에 미리 확인해보세요!

항목내용

시험 유형중간고사, 기말고사, 모의고사, 단원 평가 등
날짜시험 또는 성적 입력 날짜
점수100점 만점 기준 점수
메모선생님이 남긴 피드백 (있는 경우)
📌 참고: 성적 입력과 수정은 선생님만 할 수 있습니다. 점수가 잘못 입력된 것 같으면 선생님에게 확인을 요청하세요.

출결 확인
내 출석·결석·지각 현황 조회
출결 현황 보기
  • 1좌측 메뉴에서 출결을 클릭합니다.
  • 2이번 달 내 출결 현황이 달력 형태로 표시됩니다.
  • 3각 날짜에 출석 결석 지각 상태가 색상으로 표시됩니다.
  • 4상단 화살표로 이전 달 출결도 확인할 수 있습니다.
월별 집계 확인
  • 1달력 아래쪽에 이번 달 출석 일수, 결석 일수, 지각 횟수가 요약됩니다.
  • 2출석률(%)도 함께 표시됩니다.
⚠ 출결 기록이 잘못된 경우: 출결 수정은 선생님 또는 원장님만 가능합니다. 결석이 아닌데 결석으로 표시되어 있다면 선생님에게 수정을 요청하세요.
📌 참고: 출결 데이터는 수업료 환불 기준이 될 수 있으므로 정확히 기록하는 것이 중요합니다.
7
선생님과 소통
선생님에게 질문하거나 메시지 주고받기
메시지 보내기
  • 1좌측 메뉴에서 소통을 클릭합니다.
  • 2내 담당 선생님이 목록에 표시됩니다. 선생님 이름을 클릭합니다.
  • 3대화 화면이 열립니다. 하단 입력창에 메시지를 입력합니다.
  • 4전송(→) 버튼을 클릭하거나 Enter를 누르면 메시지가 전송됩니다.
💡 활용 예시:
📌 "선생님, 오늘 수학 숙제 3번 문제가 이해가 안 돼요. 내일 설명해 주실 수 있나요?"
📌 "오늘 몸이 좋지 않아 결석할 것 같아요."
📌 "이번 주 클리닉 일정을 확인하고 싶어요."
파일 첨부 보내기
  • 1대화 입력창 왼쪽의 📎 클립 아이콘을 클릭합니다.
  • 2전송할 파일(사진, PDF, 문서 등)을 선택합니다.
  • 3파일이 첨부되면 전송을 클릭합니다.
💡 팁: 숙제나 필기 노트 사진을 찍어서 선생님에게 보내면 피드백을 받을 수 있어요!
새 메시지 알림 확인
  • 1선생님에게 새 메시지가 오면 화면 상단에 알림 배너가 나타납니다.
  • 2배너를 클릭하면 해당 대화방으로 바로 이동합니다.
  • 3소통 메뉴의 대화 목록에서도 읽지 않은 메시지가 굵은 글씨로 표시됩니다.
📌 참고: 메시지는 담당 선생님과 1:1로 진행됩니다. 원장님도 메시지를 열람할 수 있으므로 올바른 언어를 사용해 주세요.

자주 묻는 질문 (FAQ)
EM+ 이용 중 자주 발생하는 문제와 해결 방법
Q. 로그인이 안 돼요
  • →이메일 주소와 비밀번호를 다시 확인해 주세요. 대소문자, 띄어쓰기에 주의하세요.
  • →비밀번호를 잊었다면 로그인 화면 하단 "비밀번호 찾기"를 이용하세요.
  • →계속 안 된다면 선생님 또는 원장님에게 계정 확인을 요청하세요.
Q. 로그인은 되는데 화면이 비어 있어요
  • →계정이 아직 승인되지 않은 상태입니다. 선생님 또는 원장님에게 계정 승인을 요청하세요.
  • →승인 후 다시 로그인하면 정상적으로 메뉴가 표시됩니다.
Q. 내 성적이나 숙제가 안 보여요
  • →선생님이 아직 입력하지 않은 경우입니다. 선생님에게 문의하거나 잠시 기다려 주세요.
  • →날짜 필터가 잘못 설정된 경우도 있습니다. 날짜를 다시 확인해 보세요.
Q. 출결 기록이 잘못된 것 같아요
  • →출결 수정은 선생님 또는 원장님만 가능합니다.
  • →소통 메뉴에서 선생님에게 날짜와 함께 수정 요청 메시지를 보내주세요.
Q. 스마트폰에서 화면이 이상해요
  • →Chrome 또는 Safari 최신 버전을 사용하는지 확인해 주세요.
  • →브라우저를 완전히 종료한 후 다시 열어 접속해 보세요.
  • →계속 문제가 있으면 선생님에게 알려주세요.
Q. 선생님에게 보낸 메시지가 전달이 안 된 것 같아요
  • →대화 목록에 내가 보낸 메시지가 표시되면 정상 전송된 것입니다.
  • →선생님이 수업 중일 경우 답장이 늦을 수 있습니다. 잠시 기다려 주세요.
  • →급한 연락은 전화 또는 문자를 이용하세요.
