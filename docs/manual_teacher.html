로그인 및 화면 구성
선생님 계정으로 처음 접속하는 방법과 화면 구성
시스템 접속 및 로그인
  • 1브라우저에서 https://em-plus-react.vercel.app 에 접속합니다.
  • 2원장님이 발급해 준 이메일과 비밀번호로 로그인합니다.
  • 3처음 가입 시 원장님의 계정 승인이 필요합니다. 승인 전에는 메뉴가 비활성화됩니다.
  • 4승인 완료 후 로그인하면 선생님 전용 대시보드가 표시됩니다.
⚠ 주의: 계정 승인이 완료되기 전까지 "접근 권한 없음" 메시지가 표시될 수 있습니다. 원장님께 승인을 요청하세요.

담당 학생 조회
내가 담당하는 학생 목록 확인 및 상세 정보 조회
담당 학생 목록
  • 1좌측 메뉴 학생 관리를 클릭합니다.
  • 2원장님이 배정한 내 담당 학생 목록만 표시됩니다.
  • 3학생 이름, 학년, 담당 과목이 카드 형태로 나타납니다.
  • 4학생 카드를 클릭하면 해당 학생의 상세 정보 페이지로 이동합니다.
📌 참고: 담당 학생 목록은 원장님이 배정한 것으로, 변경이 필요하면 원장님에게 요청하세요.

3
주간 학습 플랜
학생별 주간 학습 계획 작성 및 관리
주간 플랜 작성
  • 1좌측 메뉴 학습현황 → 주간플랜을 클릭합니다.
  • 2상단에서 학생을 선택하고 날짜를 설정합니다.
  • 3요일별 학습 계획 카드에서 + 추가를 클릭합니다.
  • 4과목, 학습 내용, 목표 시간을 입력하고 저장합니다.
💡 팁: 주간 플랜은 학생도 자신의 계정에서 확인할 수 있습니다. 구체적으로 작성할수록 학생의 자기 관리에 도움이 됩니다.
플랜 복사 및 수정
  • 1이전 주 플랜을 이번 주에 복사하려면 상단 지난주 복사 버튼을 클릭합니다.
  • 2복사된 플랜은 수정 가능합니다. 항목 클릭 후 내용을 변경하고 저장합니다.
  • 3항목 삭제는 항목 우측 ✕ 버튼을 클릭합니다.
플랜 이행 체크
  • 1각 항목 좌측 체크박스를 클릭하면 완료 표시됩니다.
  • 2완료된 항목은 색이 변경되어 한눈에 구분됩니다.
  • 3완료율은 상단 요약 카드에서 확인할 수 있습니다.
4
일일 학습 기록
매일의 학습 내용 기록 및 메모 작성
일일 기록 작성
  • 1좌측 메뉴 학습현황 → 일일기록으로 이동합니다.
  • 2학생 선택 → 날짜 선택 후 기록 폼이 나타납니다.
  • 3학습 메모에 오늘 다룬 내용, 학생 반응, 특이사항을 입력합니다.
  • 4저장을 클릭하면 기록이 보존됩니다.
📌 작성 팁: "오늘 이차방정식 풀이 연습. 근의 공식 적용에 어려움 있음. 내일 반복 연습 필요"처럼 구체적으로 작성하면 클리닉 리포트와 AI 요약에 더 유용합니다.
이전 기록 조회
  • 1날짜를 이전으로 이동하면 과거 기록을 조회할 수 있습니다.
  • 2기록이 있는 날짜는 달력에서 점 표시로 구분됩니다.
  • 3과거 기록도 수정 가능합니다.
5
숙제 관리
학생별 숙제 등록 및 완료 여부 확인
숙제 등록
  • 1좌측 메뉴 학습현황 → 숙제를 클릭합니다.
  • 2학생 선택 → 날짜 선택 → + 숙제 추가를 클릭합니다.
  • 3과목, 숙제 내용, 마감일을 입력합니다. 예: "수학 교재 p.45 1~10번"
  • 4저장하면 학생 화면에도 즉시 반영됩니다.
숙제 완료 확인
  • 1숙제 목록에서 각 항목의 완료 여부를 체크합니다.
  • 2학생이 직접 완료 체크할 수도 있으며, 선생님이 수동으로 수정할 수 있습니다.
  • 3미완료 항목은 목록 상단에 강조 표시됩니다.
⚠ 참고: 숙제 완료 체크는 실제 제출 여부를 직접 확인한 후 체크하는 것을 권장합니다.
6
클리닉 관리
학생 맞춤형 심층 학습 세션 운영
클리닉 구조

클리닉은 학생의 취약 부분을 집중 지도하기 위한 세션입니다. 날짜별로 세션을 생성하고, 세션 안에 학습 항목을 기록합니다. 이 데이터가 월별 리포트와 AI 요약의 원천이 됩니다.

📌 구조: 클리닉 세션 (날짜 + 제목) → 세션 내 항목 → 월별 리포트 → AI 요약
클리닉 세션 생성
  • 1좌측 메뉴 학습현황 → 클리닉 관리를 클릭합니다.
  • 2상단에서 학생과 날짜를 선택합니다.
  • 3우측 + 세션 추가 버튼을 클릭합니다.
  • 4세션 제목(예: "영어 독해 심화")을 입력하고 저장합니다.
  • 5생성된 세션 카드가 화면에 나타납니다. 색상은 자동 지정됩니다.
클리닉 항목 입력
  • 1세션 카드 내부의 + 항목 추가를 클릭합니다.
  • 2학습 내용을 구체적으로 입력합니다.
  • 3Enter 또는 저장을 클릭합니다. 항목은 연속으로 추가 가능합니다.
💡 좋은 기록 예시:
✅ "2차 함수 그래프 — 꼭짓점 계산 3회 틀림. 공식 재정리 후 2/3 정답"
✅ "영어 시제 혼용 — 현재완료 vs 과거 구분 연습. 집중도 높음"
❌ "수학 했음" (너무 모호하면 AI 요약 품질이 낮아집니다)
항목 수정 및 삭제
동작방법
항목 수정항목 텍스트 클릭 → 인라인 편집 모드
항목 삭제항목 우측 🗑️ 아이콘 클릭
세션 제목 수정세션 카드 상단 제목 클릭 → 인라인 편집
세션 삭제세션 카드 상단 ⋯ → 세션 삭제 (하위 항목 전체 삭제)
🚨 주의: 세션 삭제 시 해당 세션의 모든 항목이 영구 삭제됩니다. 복구가 불가능합니다.
조교(assistant) 역할

조교는 클리닉 항목 입력·수정이 가능하고 세션 생성도 가능합니다. 본인이 담당으로 배정된 학생에 한해서만 작동합니다.

📌 협업 팁: 선생님이 수업 진행 중 기록이 어려울 때, 조교가 실시간으로 항목을 입력하고 수업 후 선생님이 검토·수정하는 방식이 효율적입니다.
7
클리닉 리포트 & AI 요약
월별 학습 분석 리포트 생성 및 AI 요약 활용
월별 리포트 조회
  • 1좌측 메뉴 학습현황 → 클리닉 리포트를 클릭합니다.
  • 2담당 학생 선택 → 연도/월 선택.
  • 3해당 월의 총 세션 수, 총 항목 수, 과목별 분포가 카드와 차트로 표시됩니다.
  • 4하단에 날짜별 세션 목록과 상세 항목이 펼쳐집니다.
AI 요약 사용법
  • 1리포트 화면 우측 상단 AI 요약 토글 버튼을 클릭합니다.
  • 2AI가 해당 월 클리닉 항목 전체를 분석하여 학습 패턴, 취약 분야, 진전 내용을 요약합니다.
  • 3요약 생성에 10~30초 정도 소요됩니다.
  • 4생성된 요약을 검토하고 학부모 상담 자료로 활용합니다.
💡 AI 품질 향상 팁: 클리닉 항목을 구체적으로 작성할수록 AI 요약 품질이 높아집니다. 결과까지 기록하세요.
⚠ 참고: AI 요약은 서버에 API 키가 설정된 경우에만 작동합니다. 미설정 시 오류 메시지가 표시됩니다.
리포트 인쇄 및 공유
  • 1리포트 우측 인쇄 버튼을 클릭합니다.
  • 2프린터 설정에서 PDF로 저장을 선택하여 파일로 내보냅니다.
  • 3저장된 PDF를 학부모에게 이메일로 전송하거나 상담 시 출력하여 사용합니다.
8
소통 (메시지)
학생 및 원장과의 메시지 주고받기
메시지 보내기
  • 1좌측 메뉴 소통을 클릭합니다.
  • 2대화 목록에서 대화할 학생 또는 대화방을 선택합니다.
  • 3하단 입력창에 메시지를 입력하고 전송(→)을 클릭합니다.
  • 4파일 첨부가 필요하면 클립 아이콘을 클릭하여 파일을 선택합니다.
새 메시지 수신 알림
  • 1학생으로부터 새 메시지가 오면 화면 상단에 알림 배너가 표시됩니다.
  • 2배너를 클릭하면 해당 대화방으로 바로 이동합니다.
  • 3읽지 않은 메시지는 대화 목록에서 굵은 글씨와 배지로 표시됩니다.
📌 참고: 메시지는 선생님-학생 간 1:1로 진행됩니다. 원장도 메시지 내역을 열람할 수 있으니 업무 관련 내용만 작성해 주세요.
수신자 선택
  • 1새 대화 시작 시 수신자 목록에서 체크박스로 여러 명 선택 가능합니다.
  • 2학생, 원장, 다른 선생님에게 메시지를 보낼 수 있습니다.
  • 3선택 완료 후 대화 시작을 클릭합니다.
9
성적 & 수행평가
학생 시험 성적 입력 및 수행평가 관리 (teacher 전용)
시험 성적 입력
  • 1학생 상세 프로필 → 성적 탭으로 이동합니다.
  • 2+ 성적 추가를 클릭합니다.
  • 3과목, 시험 유형(중간/기말/모의고사 등), 날짜, 점수를 입력합니다.
  • 4저장 후 차트에 즉시 반영됩니다.
⚠ 조교 제한: assistant 역할은 성적 입력이 불가능합니다. teacher 계정으로만 가능합니다.
수행평가 입력
  • 1좌측 메뉴 학습현황 → 수행평가로 이동합니다.
  • 2학생 선택 후 + 항목 추가를 클릭합니다.
  • 3수행 유형, 날짜, 점수(또는 등급), 피드백을 입력합니다.
  • 4저장 후 학생도 결과를 확인할 수 있습니다.
💡 팁: 수행평가 피드백 란을 꼼꼼히 작성하면 학생이 개선 방향을 명확히 이해할 수 있습니다.
