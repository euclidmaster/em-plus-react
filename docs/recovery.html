⚠️ clone에 딸려오지 않는 2가지

  • .envSupabase 접속 키. 보안상 GitHub에 안 올라감 → 3단계에서 다시 만듦
  • .vercel-token배포용 토큰. 배포할 때만 필요 → 4단계에서 다시 만듦

두 값 모두 대시보드에서 언제든 다시 발급할 수 있으니 잃어버려도 괜찮습니다.

준비물 설치

한 번만

새 PC에 세 가지를 설치합니다: VS Code, Git, Node.js(LTS 버전).

1

코드 내려받기

VS Code에서 Ctrl+Shift+P → Git: Clone → 아래 주소 붙여넣기 → 저장 폴더 선택.

https://github.com/euclidmaster/em-plus-react.git
2

패키지 설치

프로젝트 폴더의 터미널에서:

npm install
3

.env 다시 만들기

필수

Supabase 대시보드 → Settings → API 에서 anon public 키를 복사한 뒤, 프로젝트 루트에 .env 파일을 만들어 채웁니다.

VITE_SUPABASE_URL=https://gxnvbeoncmurgwvemvih.supabase.co
VITE_SUPABASE_ANON_KEY=여기에_anon_public_키_붙여넣기

대시보드 API 설정 열기 ↗

4

.vercel-token 다시 만들기

배포할 때만

Vercel → Settings → Tokens → Create Token. Scope는 반드시 팀 전체(All Projects) 로 (개별 프로젝트 X). 그다음 PowerShell에서 (프로젝트 폴더 안):

$t = Read-Host "토큰"          # 실행 후 토큰 붙여넣고 Enter
Set-Content .vercel-token -Value $t -NoNewline

Vercel 토큰 페이지 열기 ↗

5

실행 / 배포

npm run dev      # 로컬 미리보기 → localhost:5173
npm run deploy   # 프로덕션 배포 → em-plus-react.vercel.app
